# AGENTS.md

Любой ИИ-агент, работающий в этом репозитории: **сначала прочитай `docs/AGENT-HANDOFF.md`**
(очередь задач, журнал сессий, правила, запросы к аналитике). После работы обнови его.

Кратко: русский язык в диалоге с владельцем, сайт на американском английском в стиле GTA-сарказма,
пушить только в `main`, перед коммитом `npm run build && npm run verify:dist`, секреты не коммитить, данные не выдумывать.
