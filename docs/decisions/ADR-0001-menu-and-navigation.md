# ADR-0001: Five-group menu from one data file

- Status: accepted
- Date: 2026-10-25
- Deciders: Ser (owner), Claude

## Context
The header had 12 flat links (two rows on desktop, a long list on phones). Static pages (`scripts/lib/seo.mjs`) and the React app (`src/components/Layout.tsx`) each kept their own copy of the menu, so they drifted.

## Decision
- One data file, `src/lib/nav.json`, defines five groups (News, World, Play, Market, Agents) and the five phone bottom-tab links.
- React reads it in `src/components/NavGroups.tsx` (desktop dropdowns, phone grouped list, bottom tabs, footer columns).
- Static pages read it in `scripts/lib/seo.mjs` (same markup in plain HTML/CSS, tiny inline JS for click-to-open).
- `/map/` ("All pages") is generated by `scripts/gen-seo-pages.mjs` from the same file and is in the sitemap.
- Page URLs do not change, so no SEO loss.

## Consequences
- To add or move a page, edit only `src/lib/nav.json` (and the `blurbs` map in `gen-seo-pages.mjs` for the /map/ text).
- The Agents group is where Back Alley (ADR-0003) will be linked once it exists.
- Footer "no trackers" copy was changed to "no cookies, only anonymous page counts" because first-party counting exists (ADR-0002).
